## 三、实测抓到并当场修复的问题（随本日志同 PR 上线）

### 🔴 F1（较严重）：住院时间轴"新增/点选病程"不切换中央编辑器 → 医生写错文书
- **现象**：点「+日常病程」建了文书、点时间轴条目高亮了，但中央编辑器仍停在"入院记录"；随后输入的内容全部落进入院记录（服务端核实：course_record 空、admission_note 收下了病程内容）。
- **根因**：2026-08-14 统一文书模型后时间轴条目 type 全部变为 `medical_record`，而中央编辑区的切换判据还在等旧的 `progress_note`——切换逻辑从那天起对所有新文书是死代码。
- **修复**：时间轴选中/新建统一走与文书类型下拉相同的 `setRecordType` 路径（本地暂存/恢复 + 服务端草稿拉取 + 按新文书状态重置签发锁）。
- **波及**：仅 UI 编辑指向；数据库无脏数据（本次测试的入院记录本就不存在，未覆盖任何真实内容）。

### 🟡 F2：体征输入框不归一全角 → 全角数字进 AI 生成与病历正文
- **现象**：全角"３６．８"能进表单，保存落库时后端归一（上轮修的），但 AI 生成/质控请求带的是表单原值，生成正文出现 `T:[未测]`。
- **修复**：8 个体征输入框加 `normalize` 钩子，表单值源头归一成半角（与后端 vital_limits 同口径），组件测试三条全绿。
